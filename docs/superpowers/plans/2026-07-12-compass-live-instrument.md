# Compass "Live Instrument" — Flighty-grade redesign (execution plan for Sol Ultra)

## Context

Compass (formerly Predict; Codex's uncommitted v2 on `codex/redesign-compass-account-hub`, base `ba005f3e`, version 1.0 (2)) still opens to a bare title + a dense question form — no glanceable value, flat hierarchy, results trapped in sheets. The owner wants it to feel like **Flighty, but for astrology**: a premium liquid-glass instrument that answers *before* you ask, worth opening daily, credible to skeptics ("even just for fun"), with emilkowalski/skills motion discipline (ease-out in / ease-in out, interruptible springs, motion cohesion, reduce-motion parity) and Apple's materials rule (glass = chrome/controls; content opaque). Name stays **Compass** (owner-confirmed) — the redesign makes it literal.

**The killer mechanic:** answer *"how's the sky for what I'm about to do — right now?"* with **zero typing**. Three layers: a **Now dial** (current window as one airport-board line: "Good window for hard conversations — until 2:40 PM"), a **Today strip** (tappable timeline of 3–5 honest, time-bounded windows), and **one-tap bearings** (chips that run a reading instantly through the existing credit-gated flow). The glanceable layer is local, deterministic, free, instant — the habit loop; LLM asks stay credited — the monetization. Flagship net-new engineering: a **`DayWindowsEngine`** (SwissEphemeris-backed, trust-grade tested).

Owner decisions (2026-07-12): keep "Compass" · Sol Ultra commits the dirty baseline · execute Stages 0–6, Stage 7 (Live Activity + location planetary hours) deferred behind a separate go · plan is Compass-only (Figures verdict recorded in the appendix, not executed).

## Locked architecture decisions

- **D1 — v1 window sources (location-free)**: Moon-in-sign segment(s) + ingress boundary; Moon void-of-course; transiting-Moon exact aspects to transiting planets (the volume source, 2–4/day); existing natal whole-sign transit as an **all-day context line** (provenance-gated like `refreshTransitEvidence`); `quiet` gap windows ("favors steady focus / rest") — guarantees 3–5 honest windows for every user. Planetary hours: engine-complete + tested, UI-dormant.
- **D2 — engine emits facts; copy is a separate deterministic bank** (`DayWindowCopy`, `pick(dayOfYear % variants)`, GuidanceStyle-aware: practical / balanced / astrologyRich). Lint test forbids outcome-claim language across 366 days × 3 styles.
- **D3 — composer demoted**: collapsed behind `compass.composer.expand` ("Ask your own question"); auto-expands on legacy `PredictionDraft` (keeps `testPeoplePredictDraftLandsInReplyFlow` unchanged); tests gain one `expandComposerIfNeeded()` helper tap; all inner compass.* IDs untouched.
- **D4 — `timingIsAvailable` stays natal-gated (unchanged)**; separately, asks attach the current window as a `.calculated, supportsTiming: true` evidence row so readings can echo real clock bounds honestly.
- **D5 — new instrument UI in a new file** `CompassInstrumentComponents.swift` (CompassComponents is already 607 lines).
- **D6 — materials**: dial/strip/chips = `floatingGlass`/`interactiveGlass` (instrument chrome); window explanation card = `contentSurface` (reading content).
- **D7 — dial/strip free + unlimited (local)**; only bearings consume credits via existing `beginSubmission` gate; credit caption shown on the bearings row.

**Numerics**: ingress = longitude + `speedLongitude` predict → bisect ≤60s (~8 calls). **Token map**: sun→personal, moon→family, mercury→career, venus→love, mars→career, jupiter→money, saturn→career, uranus/neptune/pluto→personal, VoC/quiet→personal.
**Tests (14)**: stable fixed-date output; time-of-day invariance; ingress ±60s self-consistency; VoC start is an exact aspect (`Aspect(orb: 0.05)`); VoC spanning midnight clamps interval but derivation keeps true start; DST 23h + 25h days fully covered; polar summer/winter skip hours but keep moon windows (Longyearbyen); 12+12 contiguous hours, first = weekday ruler; provenance-gating of the context line; **366-day × 3-style language lint** (starts with Favors/Leans/Good window/Quiet; forbids will/guaranteed/bad/avoid/unlucky); evidence `.calculated` + supportsTiming + "today" scope; style changes wording not intervals; `measure{}` perf budget. `setUp` calls `BirthChartService.setup()` (existing pattern).

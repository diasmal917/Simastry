# Simastry Landing System

## Visual Thesis

Editorial fashion cinema with zodiac undertones: a dark, premium landing page where each companion arrives like a cast reveal and the background mood changes with every introduction.

## Content Plan

1. Hero
   Timed companion reveal, product thesis, direct App Store CTA
2. Core loops
   Predict their reply, decode the chemistry, meet your sign
3. Companion wall
   The twelve zodiac personalities as a premium system
4. Final CTA
   Return to one sharp promise and conversion action

## Interaction Thesis

1. Timed hero card queue inspired by editorial card reveals
2. Backdrop crossfades tied to the active companion
3. Soft parallax and depth movement inside the hero stage
4. Scroll-triggered section entrances with restrained stagger

## Brand Rules

- Quiet, premium, intimate
- Gold is the main accent
- Photography leads the hero; zodiac details are accents, not wallpaper
- Sign-specific color appears only as restrained highlights
- The hero must read like a poster before it reads like a website
- Copy stays short and product-led, not mystical filler

## Typography

- Display: `Cormorant Garamond`
- Interface: `Sora`

## Palette

- Night: `#060816`
- Ink: `#0b1024`
- Mist: `#cfd5e8`
- White: `#f7f5ef`
- Gold: `#d8bc7a`
- Gold deep: `#8d6a36`

## Motion Rules

- Default cadence: 6.2s autoplay
- Left-side copy should update cleanly, never blink out
- Transitions should feel eased and deliberate, not snappy
- Hover pauses autoplay
- Reduced motion disables autoplay, parallax, and long transforms

## Hero Layout Rules

- Full-bleed background image that changes with the active companion
- Text anchored left in a narrow, readable column
- Companion stack anchored right and driven by fashion portrait cards
- Progress and controls sit low, inside the hero field
- No generic dashboard UI, no stat strip, no logo cloud
